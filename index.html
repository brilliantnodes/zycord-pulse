    How each number is measured
    • A transaction is one certificate in a block: a transfer, a contract deployment or call, an intent fill, or a staking or admin action.
    • Signing keys are counted, not people: Zycord wallets derive a fresh key for every payment received and every change output.
    • 7-day changes compare the average of the last 7 full UTC days with the 7 full days before.
    • A payout address is the address a block reward goes to. A pool pays to one address, so a pool counts once. No address is named on this page.
    • Hashrate is computed from the difficulty target in each block header, as the node does.
    • Days are UTC. The newest day is a part day until midnight UTC.
    • Development figures count the public dev branch; lines include tests. A contributor is a distinct commit author.
    • Fees burned are not shown: past fee levels are not kept by the node, so they cannot be measured exactly from block history.
    • Supply endpoints: total supply is every ZCD created by block subsidies up to our node's height, computed exactly from Zycord's emission parameters; circulating supply is total supply minus the treasury. The founder's 3% is counted as circulating. Fees are not counted.
    • Issued supply follows Zycord's reward schedule up to the current block. The split uses the rule in the code: 94% to the miner, 3% founder share, 3% treasury.
    • Reorganisation depths count the recent events the Zycord Lab file keeps; the all-time count and the deepest come from the same file.
    • Days on target: full UTC days whose average block time is between 28.5 and 31.5 seconds.
    • Busiest 100 blocks (speed comparison): every run of 100 consecutive blocks since launch, transactions divided by the time the run took.
    • The update time at the top turns amber when the figures are more than a day old.

Theoretical: the chain’s design limit as Chainspect states it. Finality: time until a transaction cannot be reversed; “Instant” means final when the block is made. Chains count transactions differently, so compare with care. Proof-of-work chains such as Bitcoin and Zycord have no fixed finality; Bitcoin’s 1 hour is the usual six-block convention. Data from Chainspect.
